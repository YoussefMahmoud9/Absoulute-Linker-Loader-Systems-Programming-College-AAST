# Absolute Linker Loader

A Systems Programming project that implements an **Absolute Linker Loader** using Python.

The project demonstrates how object programs can be processed and loaded into memory by resolving addresses and preparing the program for execution.

## Project Overview

A linker and loader are important parts of the system software toolchain.

This project focuses on the **absolute loading process**, where the generated object program is loaded into a specific memory location without performing relocation.

## Main Concepts

The project covers:

- Object program processing
- Address handling
- Linking concepts
- Loading into memory
- Object-code manipulation
- Systems Programming

## Workflow

```text
Object Program
      ↓
Read Object Records
      ↓
Process Addresses
      ↓
Load Object Code
      ↓
Memory Representation
      ↓
Ready for Execution
